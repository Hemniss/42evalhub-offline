Use the inaccurate flag. You're invited to talk about the project, but you cannot apply the grading scale.

Mandatory part

Creation

Check that you can create a homepage as a list with contacts and that it shows on the application's abstract.
If you click on the contact, details must appear. Created contacts are persistent and will be recorded in a local database. (Reminder: you shouldn't have used the shared contact table)

Edition

Check that you can properly edit a contact.

Removal

Check that you can delete a contact.

Text messages

Check that you can text and receive text messages from a contact.
You have clear conversation history that properly shows the sender and the receiver.

Languages

Two languages are available, one as default. For the test, change the system's language.

Background

When you set the application in the background and return to the front, the time the application was set in the background must show.

Options

You must be able to change the header color through an option menu.

Graphics

The application's icon is the 42 logo.
It works in portrait and landscape mode.
