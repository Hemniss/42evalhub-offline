42 EvalHub

Centralized evaluation sheets for all 42 School projects

📚 About This Site

This platform aggregates evaluation sheets for all projects from the 42 School curriculum. It's designed to provide a centralized, easy-to-browse reference for evaluation criteria across the entire program. Be nice with the website, it's only HTML/CSS/JS, no frameworks

⚠️ Note

Not all projects are currently up-to-date or complete. The database is continuously being improved and expanded. If you notice any missing or outdated evaluation sheets, please contribute by sharing them with us.

🛠️ Why I Made This

I was tired of retrying my project because I forgot a requirement that is noted on the bottom line of the subject. So I made this website to have a quick access to all the evals.

​⭐​ How to contribute

If you notice any missing or outdated evaluation sheets, please contribute by sharing them with us by sending us an email with the HTML evaluation sheet attached.
